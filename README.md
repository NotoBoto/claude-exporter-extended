# Claude Exporter Extended

Расширение для Chrome / Edge / Brave (Manifest V3), которое экспортирует чаты, артефакты, проекты и изображения из claude.ai.
Работает целиком в браузере, без своих серверов и без ограничений.
Идея и формат API взяты из открытого проекта [agoramachina/claude-exporter](https://github.com/agoramachina/claude-exporter) (MIT). Код написан заново.

## Установка (режим разработчика)

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку `extension/`.
4. Откройте claude.ai и войдите в аккаунт. ID организации определится сам.

## Структура

```
extension/
  manifest.json
  background.js      контекстное меню, горячие клавиши, внедрение в уже открытые вкладки
  content.js/.css    плавающая кнопка и экспорт на странице claude.ai
  popup.*            всплывающее окно
  browse.*           менеджер чатов: поиск, фильтры, предпросмотр, массовый экспорт
  options.*          настройки
  lib/api.js         клиент API claude.ai (повторы, пул параллельных запросов)
  lib/core.js        дерево сообщений, ветки, артефакты, конвертеры MD/TXT/JSON/HTML
  lib/exporter.js    сборка файлов и ZIP, кеш, история экспорта, проекты, изображения
  lib/jszip.min.js   JSZip 3.10.1 (MIT)
tests/               node --test tests/core.test.js tests/exporter.test.js
```

## Важно

- Расширение пользуется **внутренним API** веб-версии claude.ai (`/api/organizations/...`). API не документирован и может поменяться. Тогда правки понадобятся в `lib/api.js` и `lib/core.js`.
- Файлы скачиваются через такие эндпоинты (проверено 2026-11-05):
  - `GET /api/organizations/{org}/files/{file_uuid}/contents` — оригинал картинки или PDF (`/preview` и `/thumbnail` отдают уменьшенные webp; они используются как запасной вариант);
  - `GET /api/organizations/{org}/conversations/{conv}/wiggle/list-files` — список файлов песочницы чата (404, если песочницы не было);
  - `GET /api/organizations/{org}/conversations/{conv}/wiggle/download-file?path=…` — файл из песочницы.
- Эндпоинты проектов (`/projects/{id}/docs`) и файлов работают по принципу best effort: если они не ответят, экспорт чатов продолжится, а ошибка попадёт в `errors.txt`.
- Данные никуда не отправляются: всё обрабатывается локально в браузере, с вашей сессией claude.ai.
- Это неофициальный инструмент, он не связан с Anthropic.
